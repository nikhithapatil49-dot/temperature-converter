# 🌡️ Temperature Converter

Simple temperature converter website.

## 🔗 Live Demo
https://nikhithapatil49-dot.github.io/temperature-converter/

## What it does?
- Type Celsius -> Auto converts to Fahrenheit & Kelvin
- Type Fahrenheit -> Auto converts to Celsius & Kelvin  
- Type Kelvin -> Auto converts to Celsius & Fahrenheit

## Formulas Used
- Fahrenheit = (Celsius × 9/5) + 32
- Kelvin = Celsius + 273.15

## Tech Used
- HTML
- CSS
- JavaScript

## Features
- Live conversion
- Validation for Kelvin (cannot be < 0)
- Clear button
